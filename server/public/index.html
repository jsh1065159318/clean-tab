一个专注搜索、常用入口、今日重点和随手记录的浏览器新标签页。 默认完全本地运行，数据存在你自己的设备上；需要多设备同步时，也可以连接自建后端。

它做什么

  • 搜索与网址直达

    一个输入框，输入关键词直接搜索，输入网址直接打开，按 / 随时聚焦。

  • 快捷方式

    常用站点一屏可达，可拖拽排序；浏览网页时用右键菜单把当前页面直接存进来。

  • 今日重点

    首页只展示三条未完成任务，不堆砌模块，让新标签页保持清爽。

  • 随手记录

    多笔记列表，边写边存。笔记正文存放于本地 IndexedDB，容量不受限制。

  • 20 个本地工具

    JSON 格式化、正则测试、哈希、时间戳、颜色与单位换算等，全部离线可用。

  • 专注模式

    内置番茄钟，可关联到具体任务，计时跨页面与刷新保持。

安装方式

安装包是开发者版本，未上架浏览器商店，需要手动加载。下载后请先解压。

Chrome / Edge

  1. 解压下载的 ZIP 到任意目录
  2. 地址栏打开 chrome://extensions（Edge 为 edge://extensions）
  3. 打开右上角的「开发者模式」
  4. 点「加载已解压的扩展程序」，选中解压出的目录
  5. 打开一个新标签页即可看到效果

Firefox

  1. 解压下载的 ZIP 到任意目录
  2. 地址栏打开 about:debugging#/runtime/this-firefox
  3. 点「临时载入附加组件」
  4. 选中解压目录里的 manifest.json

Firefox 的临时扩展在浏览器关闭后会失效，下次打开需重新载入。
